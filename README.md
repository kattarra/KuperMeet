# KuperMeet

**«Один раз увидел — больше не повторится»**

Telegram-first знакомства для Омска. Стек: Python, aiogram 3 и SQLite. Никаких веб-приложений и отдельного фронтенда.

## Текущий статус

Репозиторий содержит стартовый каркас. Следующие этапы: схема SQLite, регистрация и модерация, анкеты и реакции, сообщения, жалобы, Stars Premium.

## Возрастная архитектура

- Возрастные сегменты разделены на `teen` (14–17) и `adult` (18+).
- Между сегментами совместимость всегда запрещена.
- Правила разницы в возрасте находятся в `age_filter.py`.
- Подростковая совместимость подготовлена в коде, но выключена по умолчанию.
- Для включения подросткового сегмента в будущем потребуются работающая проверка возраста и отдельные меры защиты. Одного возраста, введённого самим пользователем, недостаточно.
- Два независимых флага в `.env` (`ENABLE_TEEN_SEGMENT` и `TEEN_AGE_VERIFICATION_ENABLED`) нужны, чтобы подростковый сегмент нельзя было случайно открыть одной настройкой.

## Быстрый старт

1. Установить Python 3.10+.
2. Создать виртуальное окружение: `python -m venv .venv`.
3. Активировать его и установить зависимости: `pip install -r requirements.txt`.
4. Скопировать `.env.example` в `.env` и указать `BOT_TOKEN`.
5. Запустить: `python main.py`.

Не добавляйте `.env`, токены или файл базы данных в Git.

## Развёртывание

Для первого запуска используем PythonAnywhere. Инструкцию по настройке polling/always-on и ограничениям бесплатного тарифа добавим перед деплоем.

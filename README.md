# KuperMeet

**«Один раз увидел — больше не повторится»**

Telegram-first знакомства для Омска. Стек: Python, aiogram 3 и SQLite. Никаких веб-приложений и отдельного фронтенда.

## Текущий статус

- Стартовый каркас aiogram 3.
- SQLite-схема и асинхронный слой доступа к данным.
- Возрастная сегментация и совместимость вынесены в отдельный модуль.
- Готова FSM-регистрация взрослого профиля: имя, возраст, город, фото и описание.
- Анкеты уходят в канал модерации или администраторам; approve/reject доступны только ID из ADMIN_IDS.
- Отклонённая анкета удаляется из базы; одобренному пользователю открывается главное меню.
- Готова первая версия ленты: одобренные анкеты из того же города и возрастного сегмента, без повторов.
- Реакции ❤️/👎, взаимный лайк создаёт match и отправляет пользователям ссылки на Telegram-профили.
- Бесплатный лимит — 10 лайков в день; для подписчиков предусмотрен лимит 100 (проверку подписок подключим отдельным этапом).
- Следующие этапы: входящие сообщения-запросы, жалобы, проверка подписок и Stars Premium.

## Возрастная архитектура

- В базе предусмотрены сегменты `teen` (14–17) и `adult` (18+).
- Между сегментами совместимость всегда запрещена.
- Правила разницы в возрасте находятся в `age_filter.py`.
- Подростковая регистрация и совместимость выключены: возраст младше 18 лет не сохраняется, пользователь получает сообщение о закрытом сегменте.
- Для включения подросткового сегмента в будущем потребуются работающая проверка возраста и отдельные меры защиты. Одного возраста, введённого самим пользователем, недостаточно.
- Два независимых флага в `.env` нужны, чтобы подростковый сегмент нельзя было случайно открыть одной настройкой.

## Быстрый старт

1. Установить Python 3.10+.
2. Создать виртуальное окружение: `python -m venv .venv`.
3. Активировать его и установить зависимости: `pip install -r requirements.txt`.
4. Скопировать `.env.example` в `.env` и указать `BOT_TOKEN`.
5. Указать свой Telegram ID в `ADMIN_IDS`, а канал модерации — в `MOD_CHANNEL` (либо оставить `MOD_CHANNEL` пустым и получать анкеты в личные сообщения администраторов).
6. Запустить: `python main.py`.

База `kupermeet.db` создаётся автоматически при вызове `init_db()`. Не добавляйте `.env`, токены или файл базы данных в Git.

## Структура базы

Таблицы: `users`, `views`, `matches`, `reports`, `messages`, `user_limits`, `daily_likes`. В профиле хранятся сегмент и отдельный флаг подтверждения возраста. Новые анкеты создаются с `approved = 0` и не должны попадать в ленту до решения модератора. Возраст 18+ на этом этапе указывается самим пользователем и не считается подтверждённым документально — перед публичным запуском взрослого дейтинг-сервиса нужно добавить подходящую проверку возраста.

## Развёртывание

Для первого запуска используем PythonAnywhere. Инструкцию по настройке polling/always-on и ограничениям бесплатного тарифа добавим перед деплоем.
